BEFORE YOU BEGIN

Frequently asked questions

Are my MQ5 files uploaded to a server?

No. The free analyzer uses JavaScript in your browser. We do not transmit your input file or paste to our server. Never paste API secrets into public chat or bug reports.

Can this tool fix my MT5 robot automatically?

No. It identifies error codes, code patterns and performance signals, then suggests follow-up checks. Correct fixes may require source code access, broker specifications and real testing in a demo environment.

Does it compile MQL4 or MQL5 code?

No. This is a text-based static scanner, not MetaEditor or the MetaTrader strategy tester. An empty findings list does not mean an EA compiles, works correctly or is safe.

Can I analyze an MT5 backtest HTML report?

Not directly in this version. The performance tab accepts a UTF-8 CSV containing closed-trade profit, optional commission and swap columns. It does not infer an account starting balance, so drawdown is shown in the CSV's currency rather than as an invented percentage.

Does the tool provide profitable trading strategies?

No. It cannot predict markets or guarantee profits. Historical results depend on data, costs and execution; real trading carries substantial risk.
